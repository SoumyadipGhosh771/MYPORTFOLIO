# Soumyadip Ghosh — Professional Portfolio

A responsive, modern developer portfolio built with plain HTML, CSS and JavaScript.

## Run in VS Code

1. Extract the ZIP.
2. Open the extracted `soumyadip-professional-portfolio` folder in VS Code.
3. Open `index.html`.
4. Recommended: install the **Live Server** extension in VS Code.
5. Right-click `index.html` → **Open with Live Server**.

No Node.js installation is required for this static portfolio.

## Main files

- `index.html` — page structure and content
- `css/style.css` — responsive design, animations and visual styling
- `js/script.js` — mobile menu, scroll reveal and dynamic year

## Personalize

Change the following in `index.html`:
- Email
- Phone number
- Project links
- GitHub / LinkedIn links if you want to add them
- About text

The portfolio content is based on the provided resume and the project details supplied for the portfolio.
